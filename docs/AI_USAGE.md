# AI 工具使用说明

本项目开发过程中使用 OpenAI Codex 辅助完成以下工作：

- 根据比赛技术方案和 `docs/requirements.md` 整理实现边界与测试目标。
- 生成并迭代 Flex 扫描器、Bison 文法、AST 数据结构、RV64GC 后端和 CLI 初稿。
- 生成单元、CLI、官方压缩包编译/运行测试工具。
- 分析 RISC-V psABI、数组初始化、长偏移、混合参数和 Spike PTY 输入问题。
- 起草本设计说明、构建说明和第三方归属说明。

人工复核和修改范围包括：对照官方 140 个功能及 60 个性能样例逐例验证；检查生成
汇编可由 `riscv64-unknown-elf-gcc -march=rv64gc -mabi=lp64d -mcmodel=medany`
汇编；修正多维初始化、参数分类、大偏移、循环常量传播和 PTY 驱动；确认 O1 不含
测例识别；审阅诊断、资源限制、文件替换和第三方许可证。

提交前应由参赛成员继续进行代码逐行审阅、性能分析和答辩准备。AI 生成内容不替代
团队对源码原创性、正确性与竞赛规则合规性的责任。
